## Deploying to Azure Static Web Apps

1. portal.azure.com → Create Resource → Static Web App
2. Connect to `michaelmatibag/digital-landlord`
3. App location: `/sites/lubbockbiohazardcleanup`
4. Output location: blank
5. Copy the assigned `*.azurestaticapps.net` URL

## Pointing DNS in Namecheap

1. Namecheap → lubbockbiohazardcleanup.com → Advanced DNS
2. CNAME: Host=`www` → Value=your Azure URL
3. URL Redirect: Host=`@` → `https://www.lubbockbiohazardcleanup.com`
4. Azure → Custom Domains → add `www.lubbockbiohazardcleanup.com`
